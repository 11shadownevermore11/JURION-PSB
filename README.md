# JURION-PSB

Веб-ассистент для кейса ПСБ Hack&Change. React-интерфейс обращается к Python API по `/api/v1`. Сервер использует существующие поиск, правила применимости и проверку ответов Jurion. История и попытки сохраняются в SQLite. Цитаты указывают на неизменяемую версию загруженной базы.

## Запуск через Docker Compose

Из корня проекта:

cp .env.example .env
mkdir -p data


1. Положите оригинальный архив организаторов в `data/knowledge-base.zip`.
2. Заполните в корневом `.env` параметры `LLM_BASE_URL`, `LLM_API_KEY` и `LLM_MODEL` для доступного вам OpenAI-совместимого API. Например, если полный URL генерации заканчивается на `/v1/chat/completions`, значение `LLM_BASE_URL` должно заканчиваться на `/v1`. URL прокси организаторов используйте в окружении, где он доступен.
3. Выполните:
docker compose up --build

Откройте [http://localhost:8080](http://localhost:8080). Чат и [статус API](http://localhost:8080/api/health) доступны с одного адреса. Статус проверяет загрузку корпуса. Доступ к модели проверяется при отправке вопроса. При необходимости используйте `podman compose up --build` с установленным Compose-провайдером.

Архив базы и `.env` исключены из Git. Docker хранит историю и снимки документов в томе `jurion_state`. Бэкенд запускается одним экземпляром на эту базу SQLite. Для демонстрации с закрытым корпусом используйте доступ к приложению через защищённый контур: cookie разделяет истории браузеров, а доступ к документам получает любая сессия внутри приложения.

## Локальная разработка

Нужны Python 3.11+ и Node.js 22. В первом терминале из корня проекта:


set -a
. ./.env
set +a
python3 backend/web_api.py


Во втором терминале:

cd frontend
npm ci
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173) или [виджет](http://localhost:5173/#/widget). Vite проксирует `/api` на `127.0.0.1:8000`. Быстрая демонстрация интерфейса без базы и модели доступна командой `VITE_USE_MOCKS=true npm run dev` из каталога `frontend`.

## Проверка

1. Отправьте вопрос по документу из базы знаний.
2. Откройте номер основания, затем вкладку «Документ целиком».
3. Обновите страницу в том же браузере. Диалог и состояние обработки восстановятся.

Сборка фронтенда: `npm --prefix frontend run build`. HTTP API реализует контракт в `frontend/src/api/types.ts` и `frontend/src/api/client.ts`. Точка входа для отдельной автоматической проверки ПСБ — `backend/solution.py`. Для загрузки на платформу соберите отдельный ZIP с исходными модулями в корне согласно регламенту.
